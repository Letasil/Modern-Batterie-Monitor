## Modern-Batterie-Monitor

- Die Release-Datei `modern-batterie-monitor.js` ist als einzelnes Marketplace-Asset enthalten.
- Alle neun Sprachdateien sind in der Karte eingebettet. Der Ordner `translations/` bleibt für manuelle Installationen und Bearbeitungen enthalten.
- Das ZIP enthält die JavaScript-Datei direkt im Hauptverzeichnis.

Nach dem Erstellen wird das Release zunächst als Entwurf angelegt. Bitte die Assets prüfen und anschließend in GitHub **Publish release** auswählen.
